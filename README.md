# ️ Бункер — Telegram-бот с ИИ-вердиктом

Telegram-бот для игры в настольную игру "Бункер" с генерацией финального разбора от нейросети.

##  Как играть
1. Добавьте бота в группу
2. Нажмите "Новая игра"
3. Игроки присоединяются кнопкой
4. Создатель запускает игру — всем в личку приходят карточки
5. Обсуждайте, голосуйте, изгоняйте лишних
6. В конце нейросеть проанализирует ваш выбор!

## ✨ Особенности
- 🎲 Случайные карточки (профессия, здоровье, навык, хобби, инвентарь)
- 🌍 Динамические сценарии катастроф и бункеров
- 🗳️ Анонимное голосование
- 🧠 Итог игры от нейросети (Qwen 2.5 / Dots3)
-  Вместимость бункера подстраивается под число игроков

## 🛠 Технологии
- Python + aiogram 3
- OpenRouter API (нейросеть)
- FSM для управления состояниями игры
